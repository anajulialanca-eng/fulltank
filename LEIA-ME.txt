FULLTANK V5 — LOGIN E GARAGEM COMPARTILHADA

ARQUIVOS PARA O GITHUB
Envie todo o conteúdo desta pasta mantendo as pastas css e js.

ANTES DE TESTAR
1. Firebase Console > Firestore > Regras.
2. Apague as regras existentes.
3. Cole o conteúdo do arquivo firestore.rules.
4. Clique em Publicar.
5. Firebase Console > Authentication > Configurações > Domínios autorizados.
6. Confirme que anajulialanca-eng.github.io está autorizado. Se não estiver, adicione.

FUNCIONALIDADES DESTA VERSÃO
- Criar conta, entrar e recuperar senha.
- Criar garagem ou entrar por código.
- Veículos, abastecimentos e manutenções sincronizados.
- Histórico identifica quem cadastrou.
- Administrador pode excluir veículos e qualquer registro.
- Membro pode excluir os próprios abastecimentos/manutenções.
- Valores aceitam 1750,35 e 1.750,35.
- Dados separados por garagem.

IMPORTANTE
A configuração Firebase do app Web não é uma senha. A proteção dos dados depende principalmente das regras do Firestore.
